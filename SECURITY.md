# Security Policy

## Supported Versions

Security fixes are applied to the latest released version and the `main` branch.

## Reporting A Vulnerability

Do not report vulnerabilities through public pull requests or commits.

Use GitHub private vulnerability reporting for this repository:

<https://github.com/sabbasth/tidy-wow/security/advisories/new>

Include the affected version, reproduction steps, expected and actual behavior, and any suggested mitigation. You should receive an acknowledgement within seven days.
